# 自分の配色の JSON

OBB(PC 版・Android 版)の「自分の配色」は、1 つの JSON で受け渡せます。設定の「自分の配色」で「JSON をコピー」「JSON を貼り付け」、
バックアップの「配色を書き出す」「配色を読み込む」が、この形を読み書きします。PC 版と Android 版で同じ形です。

```json
{
  "from": "soft-dark",
  "base": "#1B1D22",
  "surface": "#202329",
  "text": "#D4D7DD",
  "accent": "#8B93D9",
  "unread": "#D08AA3",
  "own": "#3EC7A0",
  "colors": {
    "bar": "#262A31",
    "textMuted": "#9AA1AD",
    "newBadge": "#F2C14E",
    "markFav": "#F2C14E",
    "lineBg": "#161A22"
  },
  "accentPick": ""
}
```

## 必ず入れるもの(6 色)

色は `#RRGGBB`(大文字・小文字どちらでも)。

| キー | 何の色 |
|---|---|
| `from` | もとにした配色のキー(`indigo`・`amber-teal`・`soft-dark`・`discord-dark`・`line-light`・`gray`・`light-gray`・`nord`・`contrast`・`line-dark`・`x-dim`・`mono`・`oled`)。リンク・名前・人気の色を、選んでいなければこの配色から借りる。知らないキーは `light-gray` |
| `base` | 地(スレ一覧・スレ表示の背景) |
| `surface` | 面(レス・上下の帯) |
| `text` | 字(いちばん濃い字) |
| `accent` | 強調(ボタン・選んだ印・タブの下線) |
| `unread` | 未読(未読の数の札・「ここから未読」の線) |
| `own` | 自分の書き込み(左の帯) |

6 色から、帯・線・薄い字・既読のスレタイなどを計算で作ります(地が暗ければ暗い配色として扱います)。

## あってもよいもの

- `colors` — 細かい色。選んだものだけ書きます(書かなかった色は 6 色から作った値か、配色の決まりの色)。知らないキーは読み飛ばします。
- `accentPick` — 一緒に選んでいた差し色のキー(`indigo`・`blue`・`teal`・`green`・`orange`・`red`・`pink`・`purple`)。空か無しなら「テーマの色」。

## `colors` のキー

| まとまり | キー | 何の色 | 選んでいないとき |
|---|---|---|---|
| 面・線 | `bar` | 上下の帯 | 面(`surface`) |
| | `surface2` | 重ねた面(札・入力欄) | 面を字へ 6% 寄せた色 |
| | `surface3` | 選んだ面 | 面を字へ 12% |
| | `border` | 線 | 地を字へ 14% |
| | `borderStrong` | 濃い線 | 地を字へ 26% |
| 字 | `textBody` | 本文 | 字を地へ 10% |
| | `textMuted` | 薄い字(日付・ID・補足) | 字を地へ 45% |
| | `threadReadTitle` | 読んだスレのスレタイ | 字を地へ 35% |
| | `posterName` | 名前 | もとにした配色の色 |
| | `link` | リンク・アンカー | もとにした配色の色 |
| 強調・未読 | `accentText` | 強調の上の字 | 白か黒のうち読めるほう |
| | `unreadText` | 未読の札の字 | 白か黒のうち読めるほう |
| | `newBadge` | スレ一覧の「新」の札 | 暗い配色は金、明るい配色は(PC・Web は未読の色、Android は濃い金) |
| | `newBadgeText` | 「新」の札の字 | 札の上で読める色 |
| 自分・主 | `toOwn` | 自分へのレス | 水色(暗い配色 `#4DD0E1`・明るい配色 `#0B7A8C`) |
| | `op` | スレ主 | 金(`#F0B44C`・`#926019`) |
| 人気 | `heatWarm` / `heatHot` / `heatVeryHot` | 人気の 3 段階(書き込み数・被アンカー数) | もとにした配色の色 |
| 印 | `markFav` | お気に入りの印 | `#F2C14E`・`#AC8016` |
| | `markDanger` | 削除・NG・動画の印 | `#EF7470`・`#C53631` |
| | `markNew` | 新しい・画像の印 | `#5FC28A`・`#24794A` |
| | `markHot` | 人気の印 | `#F0954A`・`#CC5F00` |
| | `markLink` | リンク・ブラウザの印 | `#6AA9F0`・`#2969C2` |
| | `markPurple` | 見た目・アップロードの印 | `#B48CF0`・`#8051C7` |
| LINE 風 | `lineBg` | LINE 風のスレ表示の地 | 地に青灰を混ぜた色 |
| | `lineOwnBg` | LINE 風の自分の吹き出し | `#A6DB8A`・`#8DE055` |
| | `lineOwnText` | 自分の吹き出しの字 | `#10200A` |
| | `lineOwnLink` | 自分の吹き出しのリンク | `#0B4F9E` |

「・」で 2 つ書いた既定は、暗い配色・明るい配色の順です。色を混ぜる計算は Oklab で行います(PC 版・Android 版で同じ値になります)。

## 作り方のコツ

- 設定の「自分の配色」には見本と、本文・薄い字・強調の上の字などのコントラスト比の判定が出ます。本文は 4.5 以上、ほかは 3 以上が目安です。
- まず 6 色で全体を決め、気になる所だけ `colors` で直すのが楽です。`colors` を全部書く必要はありません。
- 共有するときは、設定の「JSON をコピー」の出力をそのまま貼れば、受け取った人は「JSON を貼り付け」で取り込めます。
