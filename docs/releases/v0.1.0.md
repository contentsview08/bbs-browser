## bbs-browser v0.1.0

掲示板を読み書きする PC 向けの専用ブラウザです。最初のリリースです。

### 対応する掲示板
5ch・エッヂ・したらば・ふたば☆ちゃんねる・kenmo.org ほか、2ch 互換の掲示板(subject.txt と dat)。板は URL を入れるだけで開けます。

### 主な機能
- タブで何本も開く。履歴は「見た順・未読・書き込んだ・お気に入り」の 1 つの画面に
- vim 風のキー操作(`?` でキーの一覧、`Ctrl+K` でコマンドパレット)
- NG(ID・名前・本文・スレタイ)と、同じ本文の連投を畳む自動 NG
- 配色(ダーク・ライトと OS に合わせる)、差し色、レスの見た目(カード・Discord 風・LINE 風・専ブラ風・まとめ風)、同梱の書体
- 画像を貼るだけで上げる(imgur・catbox・imgbb など)。位置情報(EXIF)は取り除きます
- 通知センター(自分へのレス・お気に入りのスレの新着・キーワードに合うスレ)
- 自動バックアップ(データの形が変わる版に上げるとき、上げる前の写しを残します)

### 入れ方
- **インストーラー**: `bbs-browser_0.1.0_x64-setup.exe`(または `.msi`)。SmartScreen が出たら「詳細情報」→「実行」(署名はまだ付けていません)
- **ZIP 版**: `bbs-browser_0.1.0_x64_portable.zip` を好きな所に展開して `bbs-browser.exe` を起動。ログと設定は同じフォルダの `data` に入ります
- Windows 10/11(WebView2 を使います)

### まだのもの

- 署名なしのため、初回の起動で警告が出ます
