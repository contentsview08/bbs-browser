## OBB v0.1.11

ChMate からの乗り換え(バックアップ ZIP の取り込み)、キーワードと NG の管理の作り直し、既読の進め方の作り直しが入っています。PC 版・Android 版とも、データの持ち方(DB)は変えていないので、上から入れればログ・既読・お気に入りはそのまま使えます。

### ChMate から乗り換える(PC 版・Android 版)
- 設定 → バックアップ →「ほかのアプリから取り込む」で、ChMate の「バックアップ」で書き出した ZIP から、スレのログと既読・自分の書き込みの印・★を付けたスレ・お気に入り板・NG・書き込みの履歴・スレタイのキーワードを取り込みます。進み具合の帯が出ます。壊れた dat は飛ばし、スレタイは dat から埋めます
- 数百件の NG を取り込んでも重くならないよう、NG の照合を作り直しました

### キーワード(3 つとも作り直し)
- 1 つの言葉(正規表現も使えます)か、立てた人の ID に 1 つの帯。正規表現が長くて読めないときのために**別名**を付けられます。**効く板**(すべて・開いている板・お気に入り板)と**有効 / 無効**も
- Android 版: 設定 → スレ一覧 →「キーワードの一覧」(種類のタブ・検索・長押しとなぞりの範囲選択・まとめて有効 / 無効 / 削除)。スレの長押し「スレタイで登録」「立てた人で登録」、帯の長押しも同じ編集の板で開きます
- PC 版: 設定「スレ一覧」から別のウィンドウの管理表。帯の右クリック・スレの右クリック「キーワードに登録」からも直せます
- 前の版の言葉は、最初の起動で自動で写します
- スレ一覧の帯を押して畳めます。畳んでいる帯には、見たことのあるスレの新着の合計「+N」が出ます
- タブ「キーワード」(キーワードに当たるスレだけ)と、「キーワードに当たるスレを帯で上にまとめる」のオン / オフ

### NG
- 期限の切れた一時 NG は自動で片づけます
- Android 版: NG の一覧を 1 つの画面に(種類のタブ・検索・長押しとなぞりの範囲選択・端で自動スクロール・まとめて有効 / 無効 / 削除・すべて削除)。編集の板は、有効を一番上に、種類・効く板(お気に入り板から選べます)・期限をドロップダウンに。名前・本文・スレタイの NG は、いつも編集の板で直してから足します(ID はその場で)。レスの長押しメニューの NG を「コピー・共有」の上に移し、見出しにレスの番号・名前・日時・ID を出します
- PC 版: 名前の NG も、NG の画面で直してから足します

### 既読(ここまで読んだ)の進め方(3 つとも作り直し)
- 画面の下端まで見えた(読み切れた)レスだけを、途切れずに数えます。開いてすぐは進めません。通知などからレスへ飛んで開いても、手前の読んでいないレスは既読にしません。一番下に着いたら全部読んだことに。新着が 1〜2 件で全部見えたときは、すぐ戻っても既読になります
- 設定「開く位置」の「最初の未読」は「前回読んだところ」という言葉に変えました(動きは同じです)

### スレ一覧
- お気に入りのスレを上に出します(キーワードの帯の中でも、「その他のスレ」の中でも先頭)
- Android 版: タブを切り替えたら先頭から。絞り込みやタブで 1 本もないときは理由を出します。字を小さくしたら余白も一緒に狭くなります(レス・スレ一覧・履歴の行)
- PC 版: スレの板にマウスを乗せると、スレタイの全文が説明で出ます。固定したタブからはいつも新しいタブで開き、同じスレのタブを 2 つ作りません。最大化したまま閉じても、次の起動で戻ります
- 人気レスの判定: 同じ人からのアンカーは 1 と数え、本人からのアンカーは数えません(表示の数はそのままです)

### バックアップ
- まるごとバックアップ(PC 版は .zip、Android 版は ZIP)に、書き込みの認証の状態(Cookie)も入れました。戻したあとにもう一度認証を求められません。PC 版は前の版の .db も戻せます
- 設定だけの JSON の書き出しは画面から外しました(まるごとバックアップと取り違えやすいため)。PC 版は NG・配色の「読み込む」から前の版の設定のファイルも読めます
- 「はじめの状態に戻す」を足しました(PC 版は前の DB を別名で残します)

### そのほか
- Android 版: 履歴の未読・お気に入り・書き込みのタブにも検索。メニューの履歴の小項目は最低 6 行。設定で 1 つを選ぶ項目はドロップダウンに。消す・戻す操作は赤に。設定のページを切り替えたら先頭から出ます
- 直した不具合: 通知の一覧に「勢い順」のタブが出ていた(PC 版)。スレを立てたあと、次に開くと前の文章が残っていた(PC 版)。画像履歴の画面が日時で落ちることがあった(PC 版)。まるごとバックアップの戻しが「読めませんでした」で止まっていた(Android 版)

### 入れ方
- **Windows**: `OBB_0.1.11_x64-setup.exe`、または `OBB_0.1.11_x64_portable.zip`
- **Linux**: `OBB_0.1.11_amd64.AppImage`、または `sudo apt install ./OBB_0.1.11_amd64.deb`
- **Android**: `OBB_0.1.11_android.apk`(0.1.10 の上から入れられます)
- Windows のインストーラー版と AppImage は、起動時に自動で更新されます

不具合や要望は [Issues](https://github.com/contentsview08/bbs-browser/issues) か、[掲示板の運営板](https://red-edge.net/boards/operation01) へどうぞ。
