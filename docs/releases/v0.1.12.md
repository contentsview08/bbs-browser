## OBB v0.1.12(下書き。未リリース)

見た目をまとめて切り替える「スキン」、スマホの未読の作り直し、PC の通知音と押せる通知が入っています。データの持ち方(DB)は変えていないので、上から入れればログ・既読・お気に入りはそのまま使えます。

### スキン(PC 版・Android 版)
- 配色(自分の配色・差し色)・レスの見た目・細かい表示・文字と余白をまとめたものを「スキン」と呼び、設定(Android: スキンと配色の一番下、PC: 表示の一番下)でいまの見た目に名前を付けて保存し、ドロップダウンで切り替えられます。スキンに入っている項目だけを上書きするので、当ててから気に入らない所を直せます
- 詳細設定を出すと、スキンの JSON を貼り付けて当てる・いまのスキンを JSON でコピー(PC はファイルの書き出し・読み込みも。Android は設定 → バックアップ から)。掲示板などでコピペして配れます。形は `docs/skin.md`
- 「ChMate 風」(ダーク・ライト)のスキンを `docs/skins/` に置いています(カードのレス、人気のレスは本文の色で紫 → 桃 → 赤、自分のレスと自分への返信は左の帯)
- 自分の配色に「細かい色」(帯・面・線・字・「新」の札・自分へのレス・スレ主・人気・印・LINE 風、29 色)。選んでいない色は今までどおり 6 色から作ります。自分の配色の JSON はスキンの `scheme` そのもので、互いに貼り合えます

### Android 版
- ドロワーを作り替え: お気に入り板 → お気に入りのスレ・閲覧履歴・書き込み履歴・未読 → URL を開く → 設定。閲覧履歴の小項目は広げません
- 未読は上に重なるパネルに(× か戻るで閉じると見ていたスレ・板がそのまま出ます)。左はメニュー、下に履歴のタブ、確かめている間は更新ボタンが回ります
- 未読の数え方を 1 つに(掲示板の数と手元の数の大きい方。dat 落ちは手元の数)。掲示板のレス数を覚えて起動直後から出し、スレを取得したとき・読んだとき・板の一覧を取ったときにその場で直します。ドロワー・履歴のタブの未読の札はレスの数の合計に
- お気に入りのスレ・未読の行は、読んだスレのスレタイを薄くしません(薄くするのは閲覧履歴だけ)。dat 落ちは補足の「dat 落ち」の字だけ赤に
- 読んでいないスレを「前回読んだところ」で開いた直後に、一番下へ落ちることがあったのを直しました(PC・Web も)
- アンカーを押したときに元・先のレスへ色を付けるのをやめました
- imgur・imgbox・imgbb の画面で上げる設定のときは、写真を選んだらすぐサイトの画面を開きます(確かめの窓を挟みません)

### PC 版
- 通知音(既定の音を同梱。設定 → 通知 で自分の音に差し替え・試し鳴らし)
- Windows の通知を OBB の名前とアイコンで出し、押すとそのスレを開きます(前は PowerShell の名前で、押しても何も起きませんでした)。通知は知らせの種類(お気に入りの新着・キーワード・自分への返信・新しい版)だけ、窓が前にないときだけ。お気に入り・キーワードの見張りは窓を小さくしていても続けます(前は戻したときにまとめて来ていました)
- スレ内検索で当たった語を本文・名前で目立たせます(Web も)
- レスのリンクの右クリック(開く・ブラウザで開く・リンクをコピー・Google で検索)、サムネイルの右クリック(見る・保存・URL をコピー・ブラウザで開く・Google で画像を検索)
- 画像の上げ方: サイトの画面で上げる上げ先は確かめの窓なしで渡し、API で上げたときは上がったらすぐ URL を本文に入れます(Web も)
- 画像ビューアーの Ctrl+ホイールは画像だけを拡大し、本文の字を変えません
- 最大化したまま閉じて開き直したときの復元(調べている途中)
