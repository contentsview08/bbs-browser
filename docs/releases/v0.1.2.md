## OBB v0.1.2

不具合の修正が中心です。Windows のインストーラー版と Linux の AppImage で 0.1.1 をお使いの方は、起動時に自動で更新されます。

### 安全性
- **hono-bbs のパスワード**: red-edge.net にだけ送るようにしました。前の版では、形が同じ別のサイトへ書き込むとパスワードが送られる可能性がありました。心当たりがある方は変更してください
- **画像の保存**: 中身の形式で拡張子を決め、画像でも動画でもないものは保存しません
- **設定の書き出し**: imgbb の API キーを含めません

### 直したこと
- PC: マウスジェスチャーをオフにしても動いてしまう
- PC: 「すべて消す」などが確認なしで実行される。ログを消すときも、どの入口からでも確認します
- PC: 返事のないサーバーで、更新や書き込みが止まったままになる
- 書き込みが通ったのに失敗と表示され、二重投稿になることがある
- PC: 板をすばやく切り替えると、前の板の一覧が出ることがある
- 絞り込みの結果が 1 画面に収まると、スレ全体が既読になる
- ミニマップで離れたレスへ飛べない。絞り込みで当たったレスが空で表示される
- スマホ: 同じ番号のスレが一覧にあると落ちることがある
- スマホ: YouTube などのリンクが板として開かれてエラーになり、戻れない
- Linux: レスの操作バーが切り取られる

### 変わったこと
- PC: レスとスレ一覧に右クリックのメニューを足しました。スレ一覧からは新しいタブで開けます
- PC: 本文の板のリンクをアプリで開きます
- レスの頭の空いた所を押してもポップアップが出ます
- LINE ライトの LINE 風で、選択中のレスの名前と ID を読みやすくしました
- Linux 版は Ubuntu 24.04 以降が対象です(22.04 では動きません)

### 入れ方
- **Windows**: `OBB_0.1.2_x64-setup.exe`、または `OBB_0.1.2_x64_portable.zip`
- **Linux**: `OBB_0.1.2_amd64.AppImage`、または `sudo apt install ./OBB_0.1.2_amd64.deb`

不具合や要望は [Issues](https://github.com/contentsview08/bbs-browser/issues) か、[掲示板の運営板](https://red-edge.net/boards/operation01) へどうぞ。
