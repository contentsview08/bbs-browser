## OBB v0.1.3

Linux での落ちる不具合、スレ表示の位置ずれ、文字化けの修正が中心です。全体を点検して、細かい不具合も多く直しました。

### 直したこと
- **Linux(AppImage):** 動画のあるレスを表示すると落ちる
- **スレ表示の位置ずれ:** 画像や札の読み込み、上へのスクロールで、見ているレスが動く
- **ジャンプ:** ミニマップや未読への移動で、思った所に着かないことがある
- **絞り込みを解いたとき・スレを閉じて開き直したとき:** 一番下へ飛ぶ
- **画像のアップロード:** サイトの画面で上げるとき、リンクを取りこぼす・同じ画像を渡し直すことがある
- **文字化け:** 板一覧だけ UTF-8 のサイトなどで文字が崩れる。文字コードを中身から見分けます
- **ログ:** サーバーのエラーページや空の応答で、手元のログが消える
- **閲覧履歴:** 2 ページ目を見ていても 1 ページ目へ戻される
- **設定:** 画像の読み込みの設定が、古い設定の移行で起動のたびに上書きされる。基本の文字を変えると次の起動で本文まで変わる
- **札:** 基本の文字を変えると、自分・返信などの札の大きさも変わる
- **書き込み:** 確認画面の読み違いで本文が空になることがある。道のある板で送り先が崩れる
- **安全性:** 自動で読む通信で、リダイレクト先の家の中のアドレスを読まないようにしました。設定の書き出しから秘密の値を外しました

### 変わったこと
- **右クリック:** ID・名前を右クリックすると専用の項目が出ます(カーソルを合わせると下線)。ヘッダーの右クリックは︙と同じメニューです
- **︙のメニュー:** 表示スタイルなどを小項目に分けました。押すと切り替わり、左上で戻れます
- **画像の読み込み:** 読み込み中のサムネイルを右クリックして、やめられます
- **URL のレス番号:** `/test/read.cgi/板/キー/123` のように番号のある URL は、そのレスまで飛んで光らせます
- **書体:** 選ぶと行に進み具合を出し、取得が終わってから切り替えます。ファイルはデータフォルダに置き、次からは取得しません
- **自分の配色:** テーマの設定から別の画面に分けました
- **文字と余白:** スライダーの幅を広げ、特に小さくできるようにしました
- スクロールと J/K、レスを押す操作、スレを開く処理を軽くしました
- Ctrl+Tab を速く押したときは、落ち着いてからタブを切り替えます
- **動画を再生できないとき:** 案内を出します。AppImage 版はアプリの中で再生できず、ブラウザで開きます。.deb 版は OS の部品を入れると再生できます
- **Linux:** 描画が止まったときは、記録して自動で読み直します
- 「このアプリについて」から、使っているソフトウェアとライセンスを見られます

### 入れ方
- **Windows**: `OBB_0.1.3_x64-setup.exe`、または `OBB_0.1.3_x64_portable.zip`
- **Linux**: `OBB_0.1.3_amd64.AppImage`、または `sudo apt install ./OBB_0.1.3_amd64.deb`
- 0.1.2 の Windows インストーラー版と AppImage は、起動時に自動で更新されます

不具合や要望は [Issues](https://github.com/contentsview08/bbs-browser/issues) か、[掲示板の運営板](https://red-edge.net/boards/operation01) へどうぞ。
