## OBB v0.1.6

ツリー表示と、表示スタイルの窓の作り直しを中心に、要望の多かった機能を足しました。

### ツリー表示
- 表示スタイル → スタイル で、カード・専ブラ風・まとめ風を選ぶと「ツリー表示」をオンにできます。返信が、返信先のレスのすぐ下に字下げして並びます
- 2 つ以上に返信しているレスは、返信先が 3 つまでならそれぞれの下に出し、2 回目以降は薄く出します。薄いレスを押すと、そのレスがポップアップで出ます
- 新着には印が付き、ミニマップにも出ます。既読は、1 番から途切れずに読んだ所まで進みます
- 実況モードの間は、番号の順で出します
- アンカーツリーも、ツリー表示と同じ並べ方・同じ字下げにしました

### 表示スタイルの窓
- タブを「配色・スタイル・文字と余白・細かい表示」に分けました。「スタイル」でレスの見た目を選ぶと、その見た目だけの設定が下に出ます
- Discord 風・LINE 風は、返信先の引用を「1 行・全文・出さない」から選べます
- どれか 1 つを選ぶ項目は、つまみが滑る切り替えボタンにしました
- LINE 風の暗い配色で、自分の書き込みを明るい緑の吹き出しに黒い字にしました(本物の LINE に合わせました)

### キーワード
- スレのメニューの「キーワードに登録」から、スレタイか、スレを立てた人(ID)で登録できます。登録の画面にスレタイが入るので、単語だけに削って登録できます
- 設定に「キーワード(立てた人)」の一覧が増えました。同期にも入ります

### 本文のリンク
- ドメインを見つけたらリンクにします。`ttp://`・`ttps://`・`https//`・`://`・`//`、スキームのない `example.com/path` なども https を補って開きます(`http` と書いてあれば http)
- ファイル名(`readme.txt` など)・数字・メールアドレスはリンクにしません

### 過去ログ
- 2ch 互換の掲示板(エッヂなど)で、dat 落ちして過去ログ倉庫に入ったスレを読めるようにしました(`kako` の `.dat.gz`・`.dat`)。途中まで読んでいたスレも続きが読めます

### PC 版
- レスの本文の文字を選んで右クリックすると、コピー・引用して返信・引用をコピー・このスレで検索・Google で検索・NG に、が出ます

### Android 版
- スレ一覧の右端に、今の位置が分かる細いスクロールバーを出しました
- `.mp4` などの動画のリンクに、最初のコマのサムネイルを出します(画像を自動で読む設定に従います)

### 直したこと
- **Android:** レスの番号が飛んでいるスレで、ポップアップに別のレスが出ることがある / LINE 風の自分の吹き出しの中の引用が白い字で読みにくい

### 入れ方
- **Windows**: `OBB_0.1.6_x64-setup.exe`、または `OBB_0.1.6_x64_portable.zip`
- **Linux**: `OBB_0.1.6_amd64.AppImage`、または `sudo apt install ./OBB_0.1.6_amd64.deb`
- **Android**: `OBB_0.1.6_android.apk`(0.1.5 の上から入れられます)
- Windows のインストーラー版と AppImage は、起動時に自動で更新されます

不具合や要望は [Issues](https://github.com/contentsview08/bbs-browser/issues) か、[掲示板の運営板](https://red-edge.net/boards/operation01) へどうぞ。
