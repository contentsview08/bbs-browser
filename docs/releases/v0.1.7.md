## OBB v0.1.7

ミニマップの作り直しと、画像の保存先の設定を中心に、細かい使い勝手を直しました。

### ミニマップ
- 左に中身の印(人気・画像・動画・リンク)、右に自分の印(自分のレスは丸、自分への返信は輪)を並べました。リンクの印を新しく足しました
- 人気レスの棒は、色だけでなく長さでも熱さが分かります
- 未読は網掛けをやめ、始まりの線 1 本だけにしました。いま見ている範囲(つまみ)は、配色に合った落ち着いた色にしました
- PC 版: ミニマップにカーソルを乗せると、番号と一緒にレスの本文の頭を出します

### 画像の保存先
- 設定(詳しい設定)で、保存するフォルダとファイル名を決められます。`{site}`・`{board}`・`{thread}`・`{filename}`・`{yyyy}` などの変数を使えます(例: `{site}/{board}/{filename}`)。欄の下に変数の説明と見本が出ます
- 既定は今までと同じ場所・同じ名前です。同じ名前のファイルがあるときは上書きせず「名前 (1)」にします
- Android 版: 保存先の土台を「ピクチャ」か「ダウンロード」から選べます。画像ビューアーで画像を長押しすると、そのまま保存します

### スレの最後
- 「次の未読スレへ」を、スレが短いときも見える範囲の一番下に出すようにしました。続けて押していけます
- 表示スタイル → 細かい表示 で、スレの最後に出す「次スレの候補」「次の未読スレ」をそれぞれオフにできます

### そのほか
- 検索や絞り込みの欄に、文字を消す × を付けました(文字が入っているときだけ、欄の右に出ます)
- PC 版: 文字を打つ欄の中では、日本語入力の変換のキー(Ctrl+T・F6〜F10 など)と編集のキー(Ctrl+A・Ctrl+Z など)をアプリのキー操作に使わないようにしました
- 2ch 互換の板で、スレタイの最後の角かっこを「立てた人の ID」としてそのまま扱うようにしました。スレ一覧に、立てた人の ID から作った模様のアイコンを出さないようにしました(アイコンは画像のサムネイルだけ)
- PC 版: 設定の「ボタンの配置」を、いつも縦 1 列(上が左)で並べるようにしました。↑↓ や置き場所の選択でも動かせます
- Android 版: 引き出しの「履歴」を枠の中でスクロールするようにしました。「すべて見る」「URL を開く」が隠れません

### 入れ方
- **Windows**: `OBB_0.1.7_x64-setup.exe`、または `OBB_0.1.7_x64_portable.zip`
- **Linux**: `OBB_0.1.7_amd64.AppImage`、または `sudo apt install ./OBB_0.1.7_amd64.deb`
- **Android**: `OBB_0.1.7_android.apk`(0.1.6 の上から入れられます)
- Windows のインストーラー版と AppImage は、起動時に自動で更新されます

不具合や要望は [Issues](https://github.com/contentsview08/bbs-browser/issues) か、[掲示板の運営板](https://red-edge.net/boards/operation01) へどうぞ。
