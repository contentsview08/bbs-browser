## OBB v0.1.9

画像ビューアーとタブの操作について、いただいた要望に対応しました。

### 画像ビューアー
- 開いた直後は本文を出さず、画像を広く見せるようにしました
  - Android 版: 画像をたたくと本文が出ます。たたくたびに「本文も出す → 全部隠す → 全部出す」と切り替わります
  - PC 版: 画像をクリックすると本文のパネルが出ます。もう一度クリックすると消えます
- PC 版: 画像ビューアーを右クリックか中クリック(ホイール押し)で閉じられるようにしました。どちらで閉じるかは、設定の「レス表示」→「画像ビューワーを閉じるボタン」で選べます(既定は右クリック。「使わない」も選べます)

### PC 版のタブ
- タブの帯の上でマウスホイールを回すと、タブを切り替えられるようにしました。下へ回すと右のタブ、上へ回すと左のタブに移り、端まで行くと反対の端へ回ります
  - 最初はオフです。設定の「表示」→「スレのタブ」でオンにできます
  - Shift を押しながら回すと、今までどおりタブの帯を横にスクロールします

### 入れ方
- **Windows**: `OBB_0.1.9_x64-setup.exe`、または `OBB_0.1.9_x64_portable.zip`
- **Linux**: `OBB_0.1.9_amd64.AppImage`、または `sudo apt install ./OBB_0.1.9_amd64.deb`
- **Android**: `OBB_0.1.9_android.apk`(0.1.8 の上から入れられます)
- Windows のインストーラー版と AppImage は、起動時に自動で更新されます

不具合や要望は [Issues](https://github.com/contentsview08/bbs-browser/issues) か、[掲示板の運営板](https://red-edge.net/boards/operation01) へどうぞ。
