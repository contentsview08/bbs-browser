## OBB v0.2.0

名前を bbs-browser から **OBB(Open BBS Browser)** に変えました。この版から、起動時に自動で更新できます。

### 新しいこと
- **自動更新**: 起動時に新しい版があれば、入れ替えて起動し直します。設定 → このアプリについて でオフにできます(インストーラー版だけ)
- **まちBBS** の読み書き
- **マウスジェスチャー**: 8 方向の円盤で操作します。既定はオフです
- **OS の通知**と、既読のスレの定期確認(最短 5 分。既定はオフ)
- **検索**: 少し違う言葉でも見つかり、ID でも探せます。空白で区切ると AND になります
- **NG**: レスのメニューから種類を選び、「NG から外す」もできます。スレ一覧ではスレタイか立てた人を選べます(立てた人は 1 日)
- **自分の書き込み**: スレの最後の帯から、自分のレスだけを抜き出して見られます
- **タブ**: 使うかどうかを設定できます。Ctrl+クリックで新しいタブに開きます
- **見た目**: ID の位置を選べます。名前欄を目立たなくする設定、ワッチョイの短い表示とアイコン、基本の文字の大きさを足しました
- 開けない URL は、既定のブラウザで開きます

### 直したこと
- 閲覧履歴の更新の途中で別の板を開くと、更新の終わりに画面が履歴へ切り替わる
- NG の操作で落ちることがある
- LINE 風の表示で、レスの操作の欄が横に長くなる
- 5ch の itest の URL が開けないことがある

### 0.1.0 から移るとき
自動更新は 0.2.0 からです。0.1.0 をお使いの方は、一度だけ手で入れてください。
- **インストーラー版**: `OBB_0.2.0_x64-setup.exe` を実行します。ログと設定は引き継ぎます。名前が変わったので、古い bbs-browser はアプリの一覧に残ります。動きを確かめてから、アンインストールしてください
- **ZIP 版**: 新しいフォルダに展開し、古いフォルダの `data` を丸ごと写してから起動します
- 最初の起動でデータの形を新しくします。その前に自動で写しを取ります。新しい形のデータは 0.1.0 では開けません

### 入れ方
- **インストーラー**: `OBB_0.2.0_x64-setup.exe`(または `.msi`)。SmartScreen が出たら「詳細情報」→「実行」を押します
- **ZIP 版**: `OBB_0.2.0_x64_portable.zip` を好きな所に展開して `OBB.exe` を起動します。ログと設定は同じフォルダの `data` に入ります。自動更新はせず、新しい版を通知で知らせます
- Windows 10/11(WebView2 を使います)
