# 公式サイトの画像と動画の置き場

ここに次の名前で置くと、サイト(site/index.html)がそのまま出す。なければ「準備中」の枠が出る。

| ファイル | 中身 | 大きさの目安 |
|---|---|---|
| `pc-main.png` | PC 版: スレ一覧とスレ表示が並んだ全体(暗い配色) | 1920×1080 前後 |
| `pc-thread.png` | PC 版: スレ表示の拡大(人気のレス・画像・ID の色が見える所) | 同上 |
| `pc-settings.png` | PC 版: 設定の窓 | 同上 |
| `pc-light.png` | PC 版: 明るい配色の全体 | 同上 |
| `android-list.png` | スマホ版: スレ一覧 | 1080×2400(縦のまま) |
| `android-thread.png` | スマホ版: スレ表示 | 同上 |
| `android-drawer.png` | スマホ版: 引き出し(左のメニュー) | 同上 |
| `android-settings.png` | スマホ版: 設定 | 同上 |
| `demo.mp4` | 1〜2 分の動画(音なし。起動 → 板を開く → 読む → 書く → 設定を変える)。20 MB まで。YouTube なら index.html の `YOUTUBE_ID` に ID を書く | H.264 |

個人の書き込みや ID が映っていないか確かめてから置く。
