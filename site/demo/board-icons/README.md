# 板ごとのアイコンの差し替え

このフォルダに板ID(URLで使われるもの、DBの`boards.id`)を名前に使った画像
(.png/.gif)を置くと、その板のアイコンとして使われます。ビルド・デプロイなし
(=`packages/web`を再デプロイした後、次に読み込んだページから)で自動的に反映され、
板の管理画面上の設定(`board.icon`)より優先されます。詳細な解決ロジックは
[`src/utils/branding.ts`](../../src/utils/branding.ts) の`useBoardIconOverride`を参照してください。

## 命名規則

`<板ID>-<インデックス>.<拡張子>`(インデックスは `0` から始まる連番、拡張子は`png`か`gif`。
同じインデックスに両方置いた場合は`.png`が優先されます)

例: 板ID `news` のアイコンを差し替える場合

```
public/board-icons/news-0.png
```

複数枚(`news-0.png`, `news-1.png`, ...)置くと、閲覧時刻の秒数を枚数で割った余りで
1枚を選ぶローテーションになります(詳細は[`public/branding/README.md`](../branding/README.md)と同じ仕組み)。
ライト/ダークスキームによる出し分けはありません(板自体にテーマの概念が無いため)。

何も置かれていない板は、今まで通り管理画面で設定した`board.icon`(未設定なら
板名の頭文字)が使われます。
