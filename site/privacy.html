OBB プライバシーポリシー

2026 年 11 月 9 日

OBB(Open BBS Browser。以下「このアプリ」)は、掲示板を読み書きするための、オープンソースのアプリです(Windows・Linux・Android)。開発者はサーバーを持たず、利用者のデータを受け取りません。データは利用者の端末と、利用者が同期を使う場合は利用者自身の Google ドライブにだけ置かれます。

1. 端末に置くデータ

このアプリは、使うために次のデータを利用者の端末の中に保存します。開発者には送られません。

  • 読んだスレのログ、既読の位置、閲覧履歴、お気に入り、書き込み履歴、NG の設定、アプリの設定
  • 掲示板にログインしたときの Cookie など、掲示板とのやりとりに要る情報
  • 表示した画像のキャッシュ

これらは、アプリの設定から消せます。アプリを消すか、データのフォルダを消すと、すべて消えます。

2. 掲示板などへの通信

このアプリは、利用者が開いた掲示板(5ch・したらば・まちBBS・ふたば・hono-bbs を使う掲示板など)や、本文の中の画像のある場所へ、端末から直接つなぎます。書き込みは、利用者が送ったときだけ、その掲示板へ送ります。それぞれの掲示板での情報の扱いは、その掲示板の決まりに従います。

新しい版があるかを確かめるため、GitHub(このアプリの配布の場所)へつなぎます。利用の状況を集める仕組み(アクセス解析・広告・クラッシュの報告など)は入っていません。

3. Google ドライブでの同期(使う場合だけ)

同期は既定でオフです。利用者が同期を始めたときだけ、次のとおり Google のアカウントのデータを使います。

3.1 求める許可

  • https://www.googleapis.com/auth/drive.appdata(Google ドライブの、このアプリ専用の隠しフォルダの読み書き)だけを求めます。利用者のほかのファイル・フォルダは、見ることも変えることもできません。

3.2 使う Google のデータと、使い方

  • アプリ専用の隠しフォルダ: 端末の間で閲覧履歴・既読・お気に入り・書き込み履歴・NG・設定をそろえるためのファイルを置き、読みます。中身は端末で暗号化してから置きます。鍵は利用者の端末にだけあり、Google と開発者は中身を読めません。
  • Google アカウントのメールアドレスと利用者の識別子: どのアカウントで同期しているかを画面に出すため、また、別のアカウントの同期に誤って入らないよう確かめるために読みます。端末の中にだけ置きます。
  • ドライブで使っている量: このアプリのファイルの大きさを足して、設定の画面に出します。

これらのデータを、同期のほかの目的に使うこと、開発者や第三者に送ること、広告に使うこと、人が読むことはありません。

3.3 許可の扱い

  • Google から受け取る許可(トークン)は、PC では OS の資格情報の保管庫に、Android では端末の鍵の保管庫で暗号化して置きます。
  • 2 台目の端末を加えるときは、利用者が自分で、許可と暗号化の鍵を QR かコードで渡します。このコードは、自分の端末のあいだだけで使ってください。

3.4 やめ方と消し方

  • アプリの同期の設定の「この端末で同期をやめる」で、その端末の許可と鍵を消します。「Google の接続を切る(全端末)」で、Google への許可も取り消します。
  • Google のアカウントの サードパーティとの接続 から、いつでも許可を取り消せます。
  • ドライブに置いた同期のデータは、パソコンのブラウザで Google ドライブの「設定」→「アプリの管理」→ このアプリの「オプション」→「隠しアプリデータを削除」で消せます。

3.5 Google API の利用者データのポリシー

このアプリが Google API から受け取った情報の使い方と、ほかのアプリへの受け渡しは、Google API Services User Data Policy(Limited Use の要件を含む)に従います。

4. 子ども

このアプリは、年齢を問わず個人を特定する情報を集めません。

5. このポリシーの変更

変えるときは、このページを書き換え、上の日付を新しくします。大きく変えるときは、リリースの説明でも知らせます。

6. 問い合わせ

このポリシーとデータの扱いについての問い合わせは、GitHub の Issues へどうぞ。

Summary in English

OBB is an open-source bulletin board browser. The developer runs no server and receives no user data. App data stays on your device. If you turn on sync, OBB requests only the drive.appdata scope to store encrypted sync files in its hidden app-data folder in your own Google Drive; it cannot see your other files. It also reads your Google account's email address and permission ID to show which account is syncing and to prevent joining a different account's sync. Tokens are kept in the OS credential store (PC) or the Android Keystore. Google user data is not transferred to the developer or third parties, not used for ads, and not read by humans. OBB's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. You can revoke access at any time from your Google Account, and delete the sync data from Google Drive settings → Manage apps. Contact: GitHub Issues.
